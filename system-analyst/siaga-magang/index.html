Studi Kasus Proyek

SIAGA — Sistem Informasi Agenda Kegiatan Dinas

Dikerjakan pada tahap magang di Diskominfo Kabupaten Jombang, bidang Aplikasi Informatika.

Fokus pekerjaan saya pada tahap ini adalah analisis kebutuhan, perancangan proses bisnis, dan pembuatan mockup. Halaman ini memperlihatkan bagaimana saya memahami kebutuhan dan merancang solusi sistem informasi.

Tahap magang berfokus pada perencanaan sistem. Implementasi aplikasi SIAGA secara lengkap saya kerjakan kemudian sebagai tugas akhir.
